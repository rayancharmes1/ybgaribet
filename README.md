# ybgaribet

Prototype web statique prêt à importer dans GitHub et à déployer sur Vercel.

## Lancer localement

Ouvrir `index.html` dans un navigateur. Aucun framework ni dépendance n'est nécessaire.

## Déployer sur Vercel

Importer le dépôt GitHub `ybgaribet` dans Vercel. Choisir **Other** comme framework preset, laisser la commande de build et le dossier de sortie vides, et conserver la racine du projet (`./`). Vercel servira `index.html` directement.

## Limites du prototype

- Jeu de Ludo local de démonstration, sans comptes ni multijoueur en ligne.
- Portefeuille fictif : aucun paiement, dépôt ou retrait n'est connecté.
- La roue et ses probabilités sont une simulation d'interface, sans argent réel.
- Aucun compteur de joueurs inventé.

Toute version avec argent réel nécessite une architecture serveur sécurisée, des contrôles adaptés et un prestataire de paiement autorisé.
